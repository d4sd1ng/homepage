```md
# Visual Language – Neurova

## Ziel

Definition der visuellen Hauptsprache für alle Neurova-Assets.

Gilt für:

- Homepage
- LinkedIn-Karussells
- Whitepaper
- Banner
- CTA-Komponenten
- PDFs
- Social Assets
- Präsentationen

## Grundstil

- dunkler Premium-B2B-Technologie-Look
- matte schwarze Flächen
- dunkelgrüne Verläufe
- smaragdgrüne Glow-Effekte
- goldene Premium-Akzente
- abstrakte Workflow-Architektur
- technische Industrieoptik
- strukturierte Tiefenwirkung

## Goldene Elemente

Gold wird genutzt für:

- Rahmen
- CTA-Buttons
- aktive Elemente
- Hover-Zustände
- Divider-Lines
- Premium-Highlights

## Nicht erlaubt

- blaue Hauptakzente
- violette Glow-Effekte
- generische KI-Roboter
- Stockfotos
- bunte Neonfarben
- überladene Dashboards
- futuristische SciFi-Optik

## Gesamtwirkung

- hochwertig
- technisch
- kontrolliert
- modern
- professionell
- vertrauenswürdig
```

```md
# Color Palette – Neurova

## Hauptfarben

### Deep Black

Verwendung:
- Hintergrund
- Hauptflächen
- Footer

### Graphite Black

Verwendung:
- Karten
- Layer
- Panels

### Emerald Green

Verwendung:
- Glow
- Akzentlinien
- Workflow-Verbindungen
- aktive Zustände

### Dark Emerald

Verwendung:
- Verläufe
- Tiefenflächen
- Hintergrundlayer

### Premium Gold

Verwendung:
- CTA-Buttons
- Rahmen
- Highlights
- Premium-Komponenten

## Regeln

- Gold sparsam einsetzen
- Grün für System-/Workflow-Optik
- Schwarz als Hauptbasis
- keine dominanten hellen Flächen
- keine bunten Farbverläufe
```

```md
# Component Rules

## CTA Buttons

### Primary CTA

- goldener Hintergrund
- dunkle Schrift
- Premium-Look
- große Rundungen
- leichte Schatten
- leichter Glow

### Secondary CTA

- transparenter Hintergrund
- goldener Rahmen
- goldene Schrift
- subtiler Hover-Glow

## Rahmen

- dünne goldene Linien
- subtile Lichtkante
- elegante Corner-Details
- keine dicken Rahmen

## Karten

- dunkle Oberflächen
- grüne Akzentlinien
- leichte Tiefenwirkung
- keine Glassmorphism-Optik

## Icons

- minimal
- technisch
- abstrakt
- eingebettet
- keine Cartoon-Icons
```

# branding/carousel_layout_rules.md

```md
# Carousel Layout Rules

## Format

1080 x 1350

## Aufbau

- große Headline oben
- klarer Fokusbereich
- viel Freifläche
- asymmetrisches Layout
- strukturierte Informationshierarchie

## Pflichtbestandteile

- Seitenzahl oben links
- Seite X von X
- Swipe-Hinweis unten
- CTA auf letzter Seite
- konsistente Abstände

## Hintergrund

- dunkler Premium-Look
- grün-schwarze Basis
- subtile Workflow-Architektur
- keine großen Dashboards
- keine lesbaren Textelemente im Hintergrund

## Elemente

- kleine eingebettete Analytics-Displays
- Prozesslinien
- industrielle Moduloptik
- Layer-Struktur
- Workflow-Verbindungen

## Nicht erlaubt

- Collagen
- mehrere Slides in einem Bild
- generische KI-Roboter
- helle Hintergründe
- überladene Grafiken
```
