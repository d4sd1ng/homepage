```md
# Component Rules

## CTA Buttons

### Primary CTA

- goldener Hintergrund
- dunkle Schrift
- Premium-Look
- große Rundungen
- leichte Schatten
- leichter Glow

### Secondary CTA

- transparenter Hintergrund
- goldener Rahmen
- goldene Schrift
- subtiler Hover-Glow

## Rahmen

- dünne goldene Linien
- subtile Lichtkante
- elegante Corner-Details
- keine dicken Rahmen

## Karten

- dunkle Oberflächen
- grüne Akzentlinien
- leichte Tiefenwirkung
- keine Glassmorphism-Optik

## Icons

- minimal
- technisch
- abstrakt
- eingebettet
- keine Cartoon-Icons
```
