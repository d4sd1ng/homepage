```md
# Carousel Layout Rules

## Format

1080 x 1350

## Aufbau

- große Headline oben
- klarer Fokusbereich
- viel Freifläche
- asymmetrisches Layout
- strukturierte Informationshierarchie

## Pflichtbestandteile

- Seitenzahl oben links
- Seite X von X
- Swipe-Hinweis unten
- CTA auf letzter Seite
- konsistente Abstände

## Hintergrund

- dunkler Premium-Look
- grün-schwarze Basis
- subtile Workflow-Architektur
- keine großen Dashboards
- keine lesbaren Textelemente im Hintergrund

## Elemente

- kleine eingebettete Analytics-Displays
- Prozesslinien
- industrielle Moduloptik
- Layer-Struktur
- Workflow-Verbindungen

## Nicht erlaubt

- Collagen
- mehrere Slides in einem Bild
- generische KI-Roboter
- helle Hintergründe
- überladene Grafiken
```
