```md
# Visual Language – Neurova

## Ziel

Definition der visuellen Hauptsprache für alle Neurova-Assets.

Gilt für:

- Homepage
- LinkedIn-Karussells
- Whitepaper
- Banner
- CTA-Komponenten
- PDFs
- Social Assets
- Präsentationen

## Grundstil

- dunkler Premium-B2B-Technologie-Look
- matte schwarze Flächen
- dunkelgrüne Verläufe
- smaragdgrüne Glow-Effekte
- goldene Premium-Akzente
- abstrakte Workflow-Architektur
- technische Industrieoptik
- strukturierte Tiefenwirkung

## Goldene Elemente

Gold wird genutzt für:

- Rahmen
- CTA-Buttons
- aktive Elemente
- Hover-Zustände
- Divider-Lines
- Premium-Highlights

## Nicht erlaubt

- blaue Hauptakzente
- violette Glow-Effekte
- generische KI-Roboter
- Stockfotos
- bunte Neonfarben
- überladene Dashboards
- futuristische SciFi-Optik

## Gesamtwirkung

- hochwertig
- technisch
- kontrolliert
- modern
- professionell
- vertrauenswürdig
```
