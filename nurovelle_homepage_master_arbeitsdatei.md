# **Betreff:** Ihre Potenzial-Analyse ist bestätigt - nächste Schritte

# - Kontaktdaten

### Schritt 2: Vorab-Analyse
# Wenn eine Website-URL angegeben wurde, kann vor dem Gespräch eine erste Prüfung vorbereitet werden.

# **Mögliche Inhalte:**
# - erste SEO- oder Performance-Auffälligkeiten
# - erkennbare Automatisierungspotenziale
# - erste Fragen für das Gespräch
# - kurzer Appetizer als Kompetenznachweis

### Schritt 3: Terminbuchung-Erinnerung
# **Auslöser:** Nach 24 Stunden, wenn noch kein Termin gebucht wurde.

# **Betreff:** Ihr Termin für die kostenlose KI-Potenzial-Analyse

# **Inhalt:**
# - kurze Erinnerung
# - Nutzen der Analyse
# - erneuter Terminlink
# - Hinweis: kostenlos und unverbindlich

### Schritt 4: Gesprächsvorbereitung
# **Auslöser:** 24 Stunden vor dem Termin.

# **Betreff:** Morgen ist Ihre KI-Potenzial-Analyse

# **Inhalt:**
# - Agenda für das Gespräch
# - kurze Vorbereitung
# - Meeting-Link
# - Kontaktdaten

## Gesprächsstruktur
# WICHTIG: Diese Gesprächsstruktur ist verbindlich für die kostenlose Potenzial-Analyse.

### Minuten 1-5: Kennenlernen & Erwartungen
# - kurze Vorstellung mit C64-Geschichte als Vertrauensanker
# - Agenda durchgehen
# - Erwartungen abfragen
# - Ziel des Gesprächs festlegen

### Minuten 5-20: Ist-Analyse
# - aktuelle Prozesse verstehen
# - Pain Points identifizieren
# - Zeitaufwände quantifizieren
# - Kosten aktueller Lösungen erfassen

### Minuten 20-35: Potenzial-Aufzeigung
# - konkrete Automatisierungsmöglichkeiten nennen
# - ROI-Schätzungen mit Zahlen vorbereiten
# - Technologie-Empfehlungen geben
# - Prioritäten-Matrix erstellen: Quick Wins vs. langfristige Maßnahmen

### Minuten 35-45: Nächste Schritte
# - wichtigste Punkte zusammenfassen
# - konkrete Handlungsempfehlungen geben
# - optionales Angebot für Umsetzung nur bei passendem Bedarf
# - Follow-up vereinbaren
