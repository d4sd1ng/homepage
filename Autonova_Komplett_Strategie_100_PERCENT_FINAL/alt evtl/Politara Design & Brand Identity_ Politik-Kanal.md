# Politara Design & Brand Identity: Politik-Kanal

## 🏛️ BRAND IDENTITY POLITARA

### **Positionierung:**
- **Seriös aber zugänglich** - Politik für normale Menschen
- **Faktenbasiert** - Keine Meinungsmache, nur Analyse
- **Unabhängig** - Keine Partei-Präferenz
- **Bildend** - Komplexe Themen einfach erklärt

### **Farbpalette:**
```
Primärfarben:
- Politara Rot: #DC2626 (RGB: 220, 38, 38) - Kraft, Entschlossenheit
- Dunkelrot: #991B1B (RGB: 153, 27, 27) - Seriosität
- Hellrot: #FCA5A5 (RGB: 252, 165, 165) - Zugänglichkeit

Sekundärfarben:
- Grau Dunkel: #1F2937 (RGB: 31, 41, 55) - Neutralität
- Grau Mittel: #6B7280 (RGB: 107, 114, 128) - Balance
- Grau Hell: #F9FAFB (RGB: 249, 250, 251) - Klarheit

Akzentfarben:
- Deutschland Gold: #FFD700 (RGB: 255, 215, 0) - Nationale Themen
- EU Blau: #003399 (RGB: 0, 51, 153) - Europäische Themen
- International Grün: #059669 (RGB: 5, 150, 105) - Globale Themen
- Weiß: #FFFFFF - Reinheit, Transparenz
```

### **Typografie:**
```
Hauptschrift: Roboto Slab (Google Fonts) - Seriös, lesbar
- Headlines: Roboto Slab Bold (700)
- Subheadlines: Roboto Slab Medium (500)
- Body Text: Roboto Regular (400)
- Captions: Roboto Medium (500)

Akzentschrift: Playfair Display (für Zitate)
Fallback: Georgia, Times, serif
```

### **Logo-Konzept:**
```
Name: POLITARA
Stil: Klassisch-modern, vertrauenswürdig
Symbol: Stilisierte Säule oder Waage
Farben: Politara Rot auf Weiß oder Weiß auf Rot
Mindestgröße: 140px Breite
```

## 📱 7. MOBILE-OPTIMIERUNG POLITARA

### **Besonderheiten für Politik-Content:**
```
Text-Größen:
- Fakten müssen auch auf kleinen Bildschirmen lesbar sein
- Mindestens 18px für wichtige Informationen
- Quellen-Angaben: Mindestens 12px

Kontrast:
- Hoher Kontrast für Seriosität
- Weiß auf Politara Rot: Mindestens 4.5:1
- Grau auf Weiß: Mindestens 3:1

Accessibility:
- Alt-Texte für alle politischen Bilder
- Untertitel für alle Videos
- Einfache Sprache in Beschreibungen
```
