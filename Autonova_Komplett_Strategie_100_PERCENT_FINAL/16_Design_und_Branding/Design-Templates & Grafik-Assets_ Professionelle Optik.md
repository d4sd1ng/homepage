## 🎨 BRAND IDENTITY AUTONOVA

### **Farbpalette:**
```
Primärfarben:
- Autonova Blau: #2563EB (RGB: 37, 99, 235)
- Dunkelblau: #1E40AF (RGB: 30, 64, 175)
- Hellblau: #60A5FA (RGB: 96, 165, 250)

Sekundärfarben:
- Grau Dunkel: #374151 (RGB: 55, 65, 81)
- Grau Mittel: #6B7280 (RGB: 107, 114, 128)
- Grau Hell: #F3F4F6 (RGB: 243, 244, 246)

Akzentfarben:
- Erfolg Grün: #10B981 (RGB: 16, 185, 129)
- Warnung Orange: #F59E0B (RGB: 245, 158, 11)
- Fehler Rot: #EF4444 (RGB: 239, 68, 68)
- Weiß: #FFFFFF
```

### **Typografie:**
```
Hauptschrift: Inter (Google Fonts)
- Headlines: Inter Bold (700)
- Subheadlines: Inter SemiBold (600)
- Body Text: Inter Regular (400)
- Captions: Inter Medium (500)

Fallback: Arial, Helvetica, sans-serif
```

### **Logo-Verwendung:**
```
Mindestgröße: 120px Breite
Freiraum: Mindestens 1x Logo-Höhe
Hintergrund: Weiß oder Autonova Blau
Varianten: Logo + Text, nur Logo, nur Text
```
