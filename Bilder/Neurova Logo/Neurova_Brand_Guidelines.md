# Neurova Brand Guidelines

## 1. Markenidentität
**Neurova** ist eine Premium-Marke für moderne KI-Infrastruktur und Automatisierung. Die visuelle Identität vermittelt Intelligenz, Vertrauen und technische Exzellenz.

**Slogan:** Building Intelligent Systems

---

## 2. Logo-Varianten
Das Logo-Set umfasst verschiedene Versionen für maximale Flexibilität:

| Variante | Beschreibung | Verwendung |
| :--- | :--- | :--- |
| **Hauptlogo** | Horizontale Ausrichtung mit Bildmarke und Text | Website, Präsentationen, Berichte |
| **Sekundärlogo** | Vertikale Ausrichtung (zentriert) | LinkedIn, Marketingmaterialien |
| **Icon Version** | Reduzierte Bildmarke | Favicon, App-Icons, Social Media Profilbilder |
| **Monochrome** | Rein schwarz-weiß | Druck, Dokumente |
| **Dark Mode** | Optimiert für dunkle Hintergründe | SaaS-Plattform, Dark Mode Websites |

---

## 3. Farbpalette
Die Farben wurden gewählt, um eine institutionelle und hochwertige Enterprise-Atmosphäre zu schaffen.

| Farbe | Hex-Code | Verwendung |
| :--- | :--- | :--- |
| **Matte Black** | `#05070B` | Primärer Hintergrund (Dark Mode) |
| **Deep Navy** | `#0A1630` | Primäre Akzentfarbe |
| **Enterprise Blue** | `#112B4A` | Sekundäre Akzentfarbe |
| **Soft White** | `#F5F7FA` | Text auf dunklem Grund |
| **Steel Gray** | `#8A96A8` | Sekundärer Text / Linien |
| **Institutional Gold** | `#C6A86A` | Subtile Akzente (optional) |

---

## 4. Typografie
*   **Headlines:** Code Pro SemiBold (Technisch, klar, modern)
*   **Supporting Text:** Raleway Medium (Elegant, lesbar, professionell)

---

## 5. Design-Prinzipien
*   **Minimalismus:** Weniger ist mehr. Klare Linien und ausgewogene Negativräume.
*   **Präzision:** Scharfe Kanten und geometrische Formen symbolisieren technische Genauigkeit.
*   **Skalierbarkeit:** Das Logo funktioniert sowohl auf Visitenkarten als auch auf großen Bannern.
