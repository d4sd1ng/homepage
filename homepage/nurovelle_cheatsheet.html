Nurovelle – Steuerungs-Cheatsheet (index.html)

Alle Werte sitzen im <style>-Block. Suche im Editor mit Strg/Cmd + F nach dem Selektor oder der --variable. Zeilennummern sind Richtwerte und verschieben sich beim Editieren – der Selektor ist der sichere Anker.

Alles auf einmal größer/kleiner (dein aktuelles Problem):
Es gibt eine Regel ganz unten im <style>, die auf großen Schirmen alles verdoppelt:
@media (min-width: 2560px) { html { zoom: 2; } }
• Zu klein auf deinem Schirm? Senke die Schwelle (2560px → z. B. 1440px) damit die Vergrößerung früher greift, oder erhöhe den Faktor (zoom: 2 → 2.4).
• Überall gleichmäßig größer, unabhängig vom Schirm? Erhöhe die --nv-…-size-Variablen im :root (siehe unten) – das ist der globale Schriften-Regler.
