## Sheet: Familienregeln
| Familie | Regel |
| --- | --- |
| Agenten | 1 Hauptagent pro Workflow; Nebenagenten kleiner und variierter; Container-Agent oder Sockel-Hologramm; keine Roboter |
| Speicher | Metallische Zylinder mit Varianten: Scheiben, Raster, Dreieck-Cluster, Punktwolke, Ringsegmente, Dokumentenlagen |
| Displays | Direkt als Tablet, Monitor, HUD oder Panel; nicht in Container packen |
| Objekte | Kleine freistehende Objekte erhalten Sockel; bei zu loser Wirkung optional offener Container |
| Technische Module | Dunkle Metall-/Glaskörper; kein zusätzlicher Sockel; Symbol/Schild statt Text |
