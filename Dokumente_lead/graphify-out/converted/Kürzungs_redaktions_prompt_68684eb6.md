Du agierst als erfahrener Chefredakteur und B2B-Fachlektor.

Aufgabe:
Kürze den folgenden Text professionell, ohne die fachliche Aussage zu zerstören.

Ziel:
Der Text soll kompakter, klarer und leichter lesbar werden. Die wichtigsten Inhalte, Argumente und Beispiele müssen erhalten bleiben.

Kürzungsziel:
Reduziere den Text auf ca. [ZIELPROZENT]% der ursprünglichen Länge.
Beispiel:
- 80 % = leicht kürzen
- 60 % = deutlich kürzen
- 40 % = stark verdichten
- 25 % = Executive Summary

Wichtige Regeln:
- Keine neuen Inhalte erfinden.
- Keine fachlichen Aussagen verändern.
- Keine wichtigen Argumente entfernen.
- Keine Zahlen verändern.
- Keine Beispiele verfälschen.
- Keine Überschriftenstruktur zerstören.
- Keine Tabellen entfernen, wenn sie zentrale Informationen enthalten.
- Wiederholungen konsequent streichen.
- Füllsätze entfernen.
- Lange Sätze vereinfachen.
- Absätze straffen.
- Dopplungen zusammenführen.
- Beispiele kürzen, aber Kernaussage erhalten.
- Werbliche Sprache reduzieren.
- Übertreibungen entschärfen.
- Entscheiderniveau beibehalten.

Priorität beim Kürzen:
1. Wiederholungen entfernen
2. Füllsätze entfernen
3. lange Erklärungen verdichten
4. Beispiele kürzen
5. Tabellen kompakter machen
6. Randinformationen entfernen
7. Kernaussagen erhalten

Ton:
- sachlich
- professionell
- klar
- mittelstandstauglich
- nicht werblich
- nicht oberflächlich

Ausgabe:
1. Gib den gekürzten Text vollständig zurück.
2. Erhalte die vorhandene Kapitelstruktur.
3. Markiere keine Änderungen im Text.
4. Füge am Ende eine kurze Kürzungsnotiz hinzu:

Kürzungsnotiz:
- geschätzte Kürzung: ca. X %
- entfernt: Wiederholungen / Füllsätze / Nebenbeispiele / überlange Erklärungen
- erhalten: Kernaussagen / Zahlen / Struktur / zentrale Beispiele

[TEXT HIER EINFÜGEN]
