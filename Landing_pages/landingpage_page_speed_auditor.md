## Problem-Lösung

### Das Problem
Langsame Seiten verlieren Besucher und schwächen die Nutzererfahrung. Oft liegen die Ursachen in Bildern, Skripten, Hosting oder unnötigem Code.

### Die Lösung
Page Speed Auditor zeigt die wichtigsten Bremsen und sortiert Maßnahmen nach Wirkung und Aufwand.

---

## Funktionen

### 1. Bildprüfung
Zu große oder ungeeignete Bilder werden erkannt.

**Enthalten:**
- Dateigröße
- Format
- Abmessungen
- Lazy Loading

### 2. Skript-Check
Blockierende Skripte und unnötige Ressourcen werden sichtbar.

**Enthalten:**
- JavaScript
- CSS
- Third-Party-Skripte

### 3. Mobile Prüfung
Die Seite wird aus Sicht mobiler Nutzer bewertet.

**Enthalten:**
- Mobile Ladezeit
- Layout Shift
- Interaktion

### 4. Technische Empfehlungen
Konkrete Maßnahmen werden als Aufgaben formuliert.

**Enthalten:**
- Komprimierung
- Caching
- Minifizierung

### 5. Prioritäten
Schnelle Gewinne werden von größeren technischen Aufgaben getrennt.

**Enthalten:**
- Quick Wins
- Entwicklung
- Hosting

## FAQ

### Brauche ich SEO-Vorkenntnisse?
Nein. Die Seite ist so aufgebaut, dass die Ergebnisse als klare Aufgaben und Empfehlungen verständlich sind.

### Ist das ein vollwertiges SaaS-Tool?
Für den Start wird es als Landingpage, Audit- oder Tool-Konzept genutzt. Eine technische SaaS-Umsetzung kann später folgen.

### Kann das für bestehende Websites genutzt werden?
Ja. Das Tool eignet sich besonders für bestehende Seiten, die sichtbar verbessert werden sollen.

### Was ist der nächste Schritt nach dem Check?
Die wichtigsten Punkte werden priorisiert und können einzeln umgesetzt oder in eine Potenzialanalyse übernommen werden.
